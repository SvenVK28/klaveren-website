# SCVK Media — Website Build Instructions

Read this document together with `01-Website-Design-Specification.md`, the main design brief.

## Goal
Build a polished Dutch-language portfolio and freelance-services website for SCVK Media, the personal journalism brand of Sven van Klaveren.

## Non-negotiable principles
- Use the main specification as the foundation for design and implementation.
- Treat the owner's approved mock-ups as visual references, while improving usability, accessibility, responsiveness, and structure where appropriate.
- Use the actual approved logo file. Do not redraw it unless specifically requested.
- Do not invent projects, clients, testimonials, awards, prices, qualifications, contact details, social-media URLs, or business registration numbers.
- The owner wants to write and approve the final website copy personally. Treat all proposed wording as a draft until explicitly approved.
- The owner must be able to update the live website and add content after launch. Make content editing a real, documented capability.
- Do not create a contact form that looks functional but does not actually deliver messages.

## Required pages
Home, Work, individual project pages, About, Freelance Services, Contact, a useful 404 page, and a privacy statement where appropriate.

The visible website navigation should use these Dutch labels:
- **Mijn werk** — Work
- **Over mij** — About
- **Freelance** — Freelance Services
- **Contact** — Contact

## Essential: owner-managed content
The owner should be able to add, edit, reorder, feature/unfeature, and remove projects; replace images; add article links and videos; edit About and service text; and update contact and social links.

Prefer a straightforward CMS or visual editing interface if suitable for the chosen technology and budget. If the chosen approach requires editing code or redeploying the site, explain this clearly and document the process. Do not claim that an admin dashboard exists unless it has actually been built and configured.

Before launch, demonstrate the editing workflow and provide simple handover instructions covering account access, domain and hosting control, backups, and recurring costs.

## Visual direction
Editorial, clean, professional, contemporary, calm, and approachable. Use a predominantly white background, near-black typography, and deep marine-navy accents. Petrol blue is optional and should be restrained. Use clear typography, strong alignment, purposeful photography, and generous but controlled whitespace.

## Mock-ups and assets
The owner has AI-generated mock-ups for Home, About, Freelance Services, and Contact. These are references for layout and visual style only. Text, people, project titles, and images shown in the mock-ups are placeholders unless independently confirmed. The owner must supply the actual screenshots and logo files; they are not embedded in this document.

## Before launch
Test page routes, responsive layouts, keyboard accessibility, colour contrast, image rights, video playback, page titles and meta descriptions, social links, contact-form delivery, privacy and cookie handling, HTTPS, and the owner's ability to edit content. Remove all placeholders before publishing.
