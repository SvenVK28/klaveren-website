# SCVK Media — Portfolio Content Plan

## Goal
Show as much of the owner's genuine work as possible without making the website feel cluttered. The complete portfolio can be extensive; the homepage should feature a curated selection.

## Content rules
- Use genuine work only.
- Every portfolio or news item must have at least one relevant image.
- Never invent titles, publication credits, dates, clients, or results.
- Clearly identify the owner's personal role in each project.
- Where useful, distinguish student assignments, personal projects, and paid client work.
- Publish only material the owner has permission to display.
- Make it straightforward to add new projects after launch.

## Possible categories
Use only categories that fit the actual work. The labels below are intended for the Dutch-language website:
- **Artikel** — Article
- **Interview** — Interview
- **Nieuwsvideo** — News video
- **Videoreportage** — Video report
- **Videomontage** — Video editing
- **Overig** — Other

Include filters if they make the portfolio easier to browse. Avoid empty or unnecessary filters.

## Fields for each project
- **Title**
- **Slug** (URL-friendly version of the title)
- **Category**
- **Short description** (one or two sentences)
- **Thumbnail/image** (required)
- **Role** (what Sven personally did)
- **Context** (optional)
- **Date** (optional; include only if known)
- **Publication/source URL** (optional)
- **Video URL/embed** (optional)
- **Full article or project details** (optional and subject to rights)
- **Featured on homepage** (yes/no)
- **Project type** (optional: student assignment, personal project, client work)
- **Alt text**
- **Rights/approval note** (internal confirmation before publishing)

## Project card
Show an image, category, title, concise summary, optional verified date/publication details, and a clear link. Use consistent image ratios and spacing.

## Project detail page
Where appropriate, include the title, category, main image/video, context, Sven's role, article/media link, and related work or a return link. For some projects, a short detail page linking to the original publication may be sufficient.
