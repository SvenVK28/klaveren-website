# Design brief from the owner

What the owner (Sven van Klaveren) supplied on 2026-10-20 through a Google Drive folder,
copied here so it stays with the code.

| File | What |
| --- | --- |
| `00-Website-mini-Klaaf.txt` | His own words (Dutch): the domain idea `scvkmedia.nl`, the logo, and what he thinks of each mock-up. Start here. |
| `01-Website-Design-Specification.md` | The main brief, written with ChatGPT: brand, colours, type, every page, accessibility, legal, acceptance checklist. |
| `02`–`07`, `README-Build-Instructions.md` | Shorter companions: visual references, brand assets, portfolio content model, copy workflow, functional requirements, launch checklist. |
| `mockups/` | AI-generated mock-ups (layout reference only: the text, people and photos in them are made up). `home-first-draft.jpg` is an older homepage version from the Google Doc. |
| `logo/` | The logo files as supplied: navy (`scvk-media-logo-navy.png`, his standard) and black. `scripts/brand/prepare-logo.mjs` turns them into the site's assets. |

Points that differ between the documents, and what the site does:
- **Logo colour.** The spec says "black by default"; his own doc says the colour (navy) logo is the
  standard and the black one is an alternative, and all mock-ups use navy. The site uses navy.
- **Number of services.** The spec lists five; the mock-up shows six (voice-over and video report
  separately). The site starts with six, all editable.
- **Copy.** The brief stresses that he writes and approves all final text himself. The current
  text is a draft based on the spec's suggestions; the site shows a "Voorbeeldversie" banner until
  he switches it off.
